# /seal-spec Workflow

> Accept the implementation and archive the spec.

---

## Quick Reference

```
Command:      /seal-spec @2026-01-11-supabase-auth
              /seal-spec @2026-01-11-supabase-auth "Great work!"
Orchestrator: Main Agent
Agents:       Scribe (for library extraction, optional)
Output:       Archive to .catalyst/completed/ + Library item (optional)

Note: Git commits are made during /forge-spec (RED FLAG and GREEN FLAG commits).
      This workflow verifies commits exist and handles archiving.
```

## Phase Details

### Phase 1: Final Verification

```
┌─────────────────────────────────────────────────────────────────┐
│  📍 FINAL VERIFICATION                                          │
│  ─────────────────────                                          │
│                                                                 │
│  1. TDD Compliance Check:                                       │
│     ├── Read tasks.md Progress section                          │
│     ├── Verify tests were written first                         │
│     └── Check validation.md shows TDD compliance                │
│                                                                 │
│  2. Validation Check:                                           │
│     ├── Verify all validation checks passed                     │
│     └── Review handoff.md for completeness                      │
│                                                                 │
│  3. User Review:                                                │
│     ├── Check user has reviewed                                 │
│     └── Note any user feedback                                  │
│                                                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  IF TDD WAS NOT FOLLOWED:                                │   │
│  │                                                          │   │
│  │  ❌ APPROVAL BLOCKED                                     │   │
│  │                                                          │   │
│  │  TDD compliance not verified. Cannot approve.            │   │
│  │                                                          │   │
│  │  Action: Return to /forge-spec and follow TDD process.   │   │
│  │          Then /audit-spec, then /seal-spec.        │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Phase 2: Verify Git State

```
┌─────────────────────────────────────────────────────────────────┐
│  📍 VERIFY GIT STATE                                            │
│  ───────────────────                                            │
│                                                                 │
│  Note: Commits were made during /forge-spec workflow.           │
│  This phase verifies the expected state exists.                 │
│                                                                 │
│  1. Detect worktree or branch mode:                              │
│     IF .catalyst/worktrees/{spec-slug} exists:                   │
│       cd into worktree (worktree mode)                           │
│     ELSE:                                                        │
│       Verify current branch:                                     │
│       $ git branch --show-current                                │
│       Expected: feat/{spec-slug}                                 │
│       (e.g., feat/2026-01-11-supabase-auth)                      │
│                                                                 │
│     ┌──────────────────────────────────────────────────────┐    │
│     │  ❌ IF NEITHER WORKTREE NOR CORRECT BRANCH           │    │
│     │                                                      │    │
│     │  "Expected branch feat/{spec-slug} but found {x}"    │    │
│     │  "Did /forge-spec complete successfully?"            │    │
│     │                                                      │    │
│     │  Action: Return to /forge-spec or /forge-spec-worktree│   │
│     └──────────────────────────────────────────────────────┘    │
│                                                                 │
│  2. Verify commits exist:                                       │
│     $ git log --oneline -5                                      │
│                                                                 │
│     Look for:                                                   │
│     - test({scope}): write failing tests for {spec}  [RED]      │
│     - feat({scope}): implement {spec}                [GREEN]    │
│                                                                 │
│  3. Check for uncommitted changes:                              │
│     $ git status --porcelain                                    │
│                                                                 │
│     If changes exist:                                           │
```

### Phase 4: Archive Spec

```
┌─────────────────────────────────────────────────────────────────┐
│  📍 ARCHIVE SPEC                                                │
│  ───────────────                                                │
│                                                                 │
│  1. Move spec to completed:                                     │
│                                                                 │
│     FROM: .catalyst/specs/2026-01-11-supabase-auth/             │
│       TO: .catalyst/completed/2026-01-11-supabase-auth/         │
│                                                                 │
│  2. Update spec.md status:                                      │
│                                                                 │
│     ┌──────────────────────────────────────────────────────┐    │
│     │  > Status: COMPLETE                                  │    │
│     │  > Completed: 2026-01-11                             │    │
│     │  > Branch: feat/2026-01-11-supabase-auth             │    │
│     └──────────────────────────────────────────────────────┘    │
│                                                                 │
│  3. Commit the archive:                                         │
│     $ git add .                                                 │
│     $ git commit -m "chore: archive {spec-slug}"                │
│                                                                 │
│  4. IF in worktree (.catalyst/worktrees/{spec-slug} exists):    │
│     $ cd <repo-root>                                            │
│     $ git worktree remove .catalyst/worktrees/{spec-slug}       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
