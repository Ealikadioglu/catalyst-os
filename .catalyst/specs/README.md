# Specifications

Run `/catalyze-spec "description"` to create a new spec.

## Structure

```
specs/
├── YYYY-MM-DD-{feature}/
│   ├── planning/
│   │   ├── requirements.md
│   │   ├── research.md
│   │   └── visuals/
│   ├── implementation/
│   │   ├── tasks.md
│   │   ├── tests/
│   │   └── progress.md
│   └── validation/
│       ├── test-results.md
│       ├── quality-report.md
│       └── sign-off.md
└── completed/
```
