# UI Pattern Hunting

Find design inspiration and patterns.

## When to Use

- No designs provided
- Seeking UI inspiration
- Researching design patterns

## Sources

- **Dribbble** - Creative design shots
- **Mobbin** - Real app screenshots
- **Competitors** - Similar products

## Process

1. **Define what to find**
   - Feature type
   - Platform (web/mobile)
   - Style preference

2. **Search inspiration sites**
   ```
   Use web_search:
   "site:dribbble.com [feature] UI"
   ```

3. **Analyze patterns**
   - Layout structure
   - Component usage
   - Visual hierarchy

4. **Document findings**
   - Save references to visuals/

## Output Format

```markdown
## UI Research: {Feature}

### Pattern Summary
Most implementations include:
- [Common element]

### Inspiration References
1. **[Source]**
   - Style: [description]
   - Notable: [what stands out]

### Recommended Approach
- Layout: [recommendation]
- Components: [recommendation]
```
