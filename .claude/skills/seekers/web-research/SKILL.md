# Web Research

Search the web for technical information.

## When to Use

- Finding implementation examples
- Researching best practices
- Looking up error solutions

## Process

1. **Formulate search query**
   - Be specific
   - Include technology names
   - Add "best practices" or "example"

2. **Execute search**
   ```
   Use web_search tool
   ```

3. **Evaluate results**
   - Check source credibility
   - Verify date/relevance

4. **Extract findings**
   - Key insights
   - Code examples
   - Warnings

## Search Patterns

```
"[technology] [feature] implementation example"
"[technology] best practices 2024"
"[error message] solution"
```

## Output Format

```markdown
## Web Research: {Topic}

### Key Findings
1. [Source]: [Finding]

### Recommended Approach
[Based on research]

### Warnings
- [Pitfall to avoid]
```
